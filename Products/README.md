# Products（产品领域层）

产品领域层只通过稳定 Contract（契约）、Pipeline（算法管线）、Rule（规则）和 Scene（场景）组合平台能力。

产品不得修改 EdgeRuntime（边缘运行时）、RuntimeAdapters（推理运行时适配器）或 Contracts（稳定契约层）。

新增行业产品原则上只增加：

- Scene（场景）
- Rule（规则）
- Pipeline Composition（算法管线组合）
- Product Configuration（产品配置）
- UI Metadata（界面元数据）
- Acceptance Cases（验收用例）
